# NoteFlow

Aplicación móvil de productividad construida con **React Native** y **Expo**. Centraliza notas de texto, listas de tareas e ideas con etiquetas en una sola experiencia, con navegación por pestañas y persistencia local.

## Gestión del proyecto

Tablero Trello: **[NoteFlow](https://trello.com/b/pEB0Awkj/noteflow)**

Columnas: Backlog → Todo → In Progress → Review → Done.
